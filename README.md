# Markdown to Excel Parser

## Описание
Программа для извлечения вопросов из Markdown-файла и экспорта в Excel

## Функциональность
- Извлечение текста вопросов.
- Сбор ссылок изображений.
- Экспорт результатов в Excel.
---

## Стек технологий
- Python
- openpyxl

## Локальное развертывание проекта

### 1. Клонировать репозиторий

```bash
git clone https://github.com/ToSky26/test-markdown-to-excel.git
cd test_excel
```

### 2. Создать виртуальное окружение
```bash
python3 -m venv venv
```

### 3 Активировать виртуальное окружение.
```bash
source venv/bin/activate
```

### 4. Установить зависимости

```bash
pip install -r requirements.txt
```

### 5. Запуск программы

```bash
python3 main.py input.md
```
